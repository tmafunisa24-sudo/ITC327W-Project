## 📖 Project Overview

**Academic Year:** 2026  

### 📌 Project Description

Click Computer and Accessories provides computer and electronic support services to clients, including cellphones, laptops, printers, televisions, and other electronic equipment.

Currently, clients request support through direct communication (phone or in-person) with staff. This manual process has several limitations:
- **No centralised tracking system** – requests can be missed or forgotten
- **Manual assignment** – technicians are assigned informally, causing delays
- **Limited visibility** – clients cannot track their request progress
- **Increased workload** – staff spend time on manual administration

This project aims to develop a **simple client-support platform** that enables clients to submit, track, and communicate about support requests efficiently. The system will be built using **Flutter** (frontend), **ASP.NET Core** (backend API), and **Supabase** (database).

## 🛠️ Technology Stack

| Component | Technology | Purpose |
|-----------|------------|---------|

| **Backend API** | ASP.NET Core 6.0 (C#) | RESTful API, business logic, request processing |
| **Database** | Supabase (PostgreSQL) | Relational database with real-time capabilities |
| **Authentication** | Supabase Auth | Secure user authentication and access control |
| **Storage** | Supabase Storage | File and asset storage for supporting evidence |
